
# React-Flask Web App

This project is a full-stack web application built with React and Flask that enables users to manage a personalized list of friends. Users can perform all CRUD (Create, Read, Update, Delete) operations to add, view, edit, and remove friends, along with details about their current company roles and brief descriptions. The application features a beautiful, simple, and minimalistic user interface, providing an intuitive experience for efficiently organizing and updating your friends’ professional information.
